# cia302

## Objects

### Program data

**0x1F50**
Firmware image, written by SDO block download

| Name              | Type   | default |
| ----------------- | ------ | ------- |
| Number of entries | uint8  | 1       |
| Program number 1  | domain | 0       |

### Program control

**0x1F51**
Start, stop and reset the downloaded program

| Name              | Type  | default |
| ----------------- | ----- | ------- |
| Number of entries | uint8 | 1       |
| Program number 1  | uint8 | 0       |

### Program software identification

**0x1F56**
Checksum of the downloaded program

| Name              | Type   | default |
| ----------------- | ------ | ------- |
| Number of entries | uint8  | 1       |
| Program number 1  | uint32 | 0       |

### Flash status identification

**0x1F57**
Status of the last flash operation

| Name              | Type   | default |
| ----------------- | ------ | ------- |
| Number of entries | uint8  | 1       |
| Program number 1  | uint32 | 0       |
